twin

Two-way sync

Newer file wins. Nothing is ever lost: replaced and deleted files go to backups.

Every day

Start it on the laptop. Finish it on the mini.

  • twin pairFinds the other Mac and trusts it once.
  • twin setupMakes it match this Mac and turns on auto sync.
  • twin syncTwo-way, with backups kept for 14 days.
  • twin linkKeeps this project folder 1:1 on both Macs.
  • twin run "fix the tests"Runs headless Claude Code on the mini.
  • twin logs -fWatches the job live.
  • twin fetchBrings its changes and its session back.

What syncs

Everything that makes it yours.

  • ConfigSettings, CLAUDE.md, skills, commands, agents, hooks and output styles.
  • SessionsTranscripts, auto memory, checkpoints, todos and plans.
  • HistoryPrompt history for ↑ and ctrl+r, merged line by line.
  • MCPYour MCP servers, and nothing else in that file.
  • ProjectsFolders you link, every file both ways, .env and .git included.

Never synced: credentials. Each Mac signs in on its own.

Cable first

Uses the USB-C or Thunderbolt link when it is plugged in, then LAN, then Tailscale.

Close the lid

The mini keeps working under caffeinate. Pick the session up later with claude --resume.

Different usernames

Home folders do not need to match. twin translates paths on every copy.

Built for agents

Every command speaks --json, and twin skill teaches Claude when to delegate.
