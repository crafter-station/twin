LinkedIn · EnglishLong

Claude Code keeps everything on the machine it runs on: your sessions, memory, skills and settings. Open a second Mac and you start from zero twin fixes that. It is an open source CLI from Crafter Station that pairs two Macs and syncs all of it both ways, over the USB-C cable and plain SSH, with no cloud in the middle It also turns a Mac mini into a machine you hand work to: send a long task with one command, close the laptop, then bring the changes back and continue the same session npm i -g @crafter/twin Site and repo: twin.crafter.run
